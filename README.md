## 🚀 Key Capabilities

- 🕵️ **Multi-Site Autonomous Monitoring**: Scans a fleet of websites every 10 minutes (ShopSphere, Swag Labs, UI Playground).
- 💫 **Visual Intelligence**: Captures screenshots of failures and highlights 'Visual Flaws' in automated reports.
- 📡 **Proactive Alerts**: High-severity issues are pushed immediately to **Telegram** with root-cause diagnosis.
- 🧠 **Regression Memory**: Tracks bug history to identify recurring issues and calculate reliability trends.
- 🔗 **Interactive Lively Scans**: Respond 'Scan Now' on Telegram to trigger an instantaneous audit on-demand.

## 🛠️ Tech Stack

- **Automation**: Playwright (via Agent Browser Wingman)
- **Intelligence**: AI-powered Root Cause Diagnosis & Severity Classification
- **Backend**: Python 3.x Scheduled Heartbeat (Cron-based)
- **Frontend**: React + Tailwind CSS Dashboard
- **Alerts**: Telegram Bot API
